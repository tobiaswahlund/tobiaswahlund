# Hi, I'm Tobias

Civil engineer (energy, environment and management) with a specialisation in system tools for sustainable development. I'm moving into software for robots and machines that see: computer vision, machine learning and the code that turns a camera picture into an action.

**Featured project: [BrickSort](https://github.com/tobiaswahlund/BrickSort)** recognises about 600 LEGO parts from a camera picture and sorts them on a simulated conveyor belt. It uses PyTorch and MuJoCo, is trained on physics-based synthetic renders plus real photos, and has the hardware interface ready for a real machine.

What I bring from engineering: thinking in whole systems, testing assumptions with data, and building things that hold up outside the lab.
